# OCM Trademark and Label Policy

**Code frei, Name geschützt.** (Code free, name protected.)

The software in projects adopting OCM is open source under an OSI-approved
license: everyone may use, modify, fork, self-host, and offer it. The label
"Open Commons Maintenance" and the project names using it are the only
protected element, as a trademark-like community label held by the model's
author (Jerome Winkel, @Jersyfi) and, eventually, a nonprofit steward.

## When you may use the OCM label

A project may describe itself as using Open Commons Maintenance if it adopts
the **mandatory core**, unchanged:

1. The code stays under an OSI-approved license (and the project commits to
   never moving to a non-OSI license; DCO instead of CLA).
2. The four guarantees hold: no feature gates, no rug-pull, no lockout on
   non-payment, no billing-related data exfiltration.
3. A free class without justification or proof exists.
4. The dormant rule exists (genuinely dormant installations pay nothing).
5. Transparency levels T1 (public rules) and T2 (annual maintenance report)
   are published.

## What the label does not grant

- The label does not make your project part of an organization. It is a
  self-declared declaration of values.
- The label does not entitle anyone to speak for OCM as a whole.

## Forks and renames

Forks that keep the mandatory core may keep the OCM label. Forks that drop
any part of it must remove the label. Offering the software **under the
project's own name** commercially (e.g. as a hosted service) requires the
maintainer's permission, which is granted for participation in the
maintenance contribution. Forks offered under a different name are entirely
free.

## Versioning

The model is versioned like software (1.0, 1.1, ...). A declaration always
states the version it follows (`ocm: "1.0"`), so rules remain auditable even
when later versions change details.

## Disclaimer

This policy is a community norm, not legal advice or a registered trademark
(yet). Registration (DPMA/EUIPO) is a later, optional step for the label
holder.
