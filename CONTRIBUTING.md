# Contributing

Contributions are welcome: code, documentation, translations, issue triage,
and security reports all count.

## DCO instead of CLA

This project uses the [Developer Certificate of Origin (DCO)](https://developercertificate.org/).
By contributing, you retain the copyright to your work; no CLA, no rights
transfer. Please sign off your commits:

```bash
git commit -s
```

The sign-off lets the project guarantee it will never relicense to a
non-OSI license ("no rug-pull"), because nobody holds all the rights alone.

## Contributors get the community tier for free

Anyone with a substantive contribution (code, docs, translation, triage,
security reports) uses all of the maintainer's projects at the community
rate for free. See `MAINTENANCE.md` in the adopting project.
